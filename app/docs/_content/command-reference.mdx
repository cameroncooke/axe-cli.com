## Discovery and readiness

### `list-simulators` and `list-devices`

```shell
axe list-simulators
axe list-devices
```

`list-simulators` prints every simulator with its UDID and state. `list-devices` lists the iPhones and iPads that Xcode knows, with any readiness problems.

### `doctor`

```shell
axe doctor --udid "$UDID"
```

Checks that a simulator is booted, or that a device is paired, in Developer Mode, connected, unlocked, with its developer disk image and screenshot service. A failed check exits nonzero.

### `displays`

```shell
axe displays --udid "$UDID"
```

Shows each screen's role, size in points, scale and orientation, which one is active, and the iPhone Duo's hinge angle. See [iPhone Duo](/docs/iphone-duo#screens).

## Reading the UI

### `describe-ui`

```shell
axe describe-ui --udid "$UDID"
axe describe-ui --point 100,200 --udid "$UDID"
axe describe-ui --agent --view navigation --udid "$UDID"
```

Prints the accessibility tree as JSON, or the element at one point. With `--agent`, a compact capture with refs; see [Agent Mode](/docs/agent-mode).

## Touch input

### `tap`

```shell
axe tap -x 120 -y 240 --udid "$UDID"
axe tap --id SearchField --udid "$UDID"
axe tap --label "Continue" --element-type Button --wait-timeout 5 --udid "$UDID"
axe tap --label "Photo" --hold 1 --udid "$UDID"
axe tap --id Map --count 2 --udid "$UDID"
axe tap --id Canvas --touches 2 --udid "$UDID"
```

Pass `-x` and `-y`, or exactly one of `--id`, `--label` or `--value`. See [Reading & Tapping](/docs/accessibility-targeting).

### `slider`

```shell
axe slider --id volume --value 75 --udid "$UDID"
```

Sets a slider to a percentage and checks the new value. Simulators only.

### `swipe`, `drag`, `draw`, `touch` and `gesture`

```shell
axe swipe --start-x 200 --start-y 600 --end-x 200 --end-y 300 --udid "$UDID"
axe drag --start-x 200 --start-y 300 --end-x 200 --end-y 500 --hold 0.6 --udid "$UDID"
axe draw 100,400 300,400 300,600 --close --udid "$UDID"
axe touch -x 150 -y 250 --down --up --delay 1.0 --udid "$UDID"
axe gesture scroll-down --until-label "Privacy" --udid "$UDID"
axe gesture pinch --scale 2 --udid "$UDID"
```

See [Swipes, Gestures & Drawing](/docs/gestures).

## Keyboard

```shell
axe type 'Hello, world!' --udid "$UDID"
printf 'Multi-line\ninput' | axe type --stdin --udid "$UDID"
axe key 40 --udid "$UDID"
axe key-sequence --keycodes 11,8,15,15,18 --delay 0.1 --udid "$UDID"
axe key-combo --modifiers 227 --key 4 --udid "$UDID"
```

See [Keyboard & Text Input](/docs/keyboard-input).

## Device

### `button`

```shell
axe button home --udid "$UDID"
axe button lock --duration 3 --udid "$UDID"
axe button lock --allow-lock --udid "$DEVICE_UDID"
```

Buttons are `home`, `lock`, `side-button`, `siri` and `apple-pay`. A button acts on the whole device; capture the screen again after Home.

### `rotate` and `hinge`

```shell
axe rotate left --udid "$UDID"
axe hinge read --udid "$UDID"
axe hinge set tabletop --udid "$UDID"
```

`rotate` works on the iPhone Duo simulator and physical devices; `hinge` on the iPhone Duo simulator. See [iPhone Duo Simulator](/docs/iphone-duo).

### `settings`

```shell
axe settings show --udid "$UDID"
axe settings set --udid "$UDID" --appearance dark --text-size large
axe settings location set --latitude 51.5 --longitude -0.12 --udid "$UDID"
axe settings status-bar preset screenshot --udid "$UDID"
```

Needs Xcode 27 or later. See [Device Settings](/docs/settings).

### `shutdown`

```shell
axe shutdown --udid "$UDID"
```

Shuts down exactly one simulator by UUID and prints `Shut down <udid> (was Booted)` or `<udid> was already shut down`. JSON is `{udid, initialState, outcome}`.

### `clipboard copy`

```shell
printf '%s' 'AXe sample' | axe clipboard copy --stdin --udid "$UDID"
```

Stages 1 to 65,536 UTF-8 bytes in one booted simulator's clipboard, verifies them by readback and prints `Copied N bytes to the clipboard of <udid> (sha256 …)`. JSON is `{udid, bytes, sha256}`. It does not paste. Both `shutdown` and `clipboard copy` report `actionOutcomeUnknown` when the effect could not be confirmed.

## Capture

```shell
axe screenshot --output screen.png --udid "$UDID"
axe record-video --output run.mp4 --fps 15 --udid "$UDID"
axe stream-video --format mjpeg --fps 10 --udid "$UDID" > stream.mjpeg
axe stream-video --format h264 --udid "$DEVICE_UDID" > device.h264
```

See [Screenshots & Video](/docs/screenshots-video).

## Automation

### `batch`

```shell
axe batch --udid "$UDID" \
  --step "tap --id Email" \
  --step "type 'cam@example.com'" \
  --step "key 40"
```

See [Batch Automation](/docs/batch).

### `agent`

```shell
axe agent "Open Settings and turn on Airplane Mode" --udid "$UDID"
```

See [Autonomous Agent](/docs/autonomous-agent).

### `init`

```shell
axe init
axe init --client claude --force
axe init --print
```

See [AI Skill](/docs/agent-skills).
