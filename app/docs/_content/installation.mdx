## Requirements

| Requirement | Notes |
|-------------|-------|
| macOS | macOS 14 Sonoma or later, on Apple silicon or Intel. |
| Xcode | Xcode 26 or Xcode 27, selected with `xcode-select`. One AXe binary runs with either. `axe settings` needs Xcode 27. |
| Simulator | A booted iOS simulator. The iPhone Duo commands need an iPhone Duo simulator runtime. |
| Physical device (optional) | An iPhone or iPad paired in Xcode, with Developer Mode on and the screen unlocked. |

## Install with Homebrew

```shell
brew install cameroncooke/axe/axe
axe --help
```

Upgrade later with:

```shell
brew upgrade axe
```

## Check a target

For a simulator:

```shell
axe list-simulators
axe doctor --udid <UDID>
```

For a physical iPhone or iPad:

```shell
axe list-devices
axe doctor --udid <DEVICE_UDID>
```

`doctor` checks that a simulator is booted, or that a device is paired, in Developer Mode, connected, unlocked and has its developer disk image and screenshot service. A failed check exits nonzero and names the check that is not ready.

<Callout variant="info" title="AXe never picks a device for you">
Every command needs an explicit `--udid`. AXe looks the UDID up among simulators first, then among the devices Xcode knows.
</Callout>

## Add the AI skill

If you use Claude Code, Codex or another agent, install the AXe skill so the agent knows how to drive the UI with agent mode:

```shell
axe init
```

To keep the skill updated as releases ship, install it from the AXe plugin marketplace instead:

```shell
claude plugin marketplace add cameroncooke/AXe && claude plugin install axe@axe
codex plugin marketplace add cameroncooke/AXe && codex plugin add axe@axe
```

See [AI Skill](/docs/agent-skills) for every option.
