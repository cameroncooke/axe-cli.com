The skill is a `SKILL.md` plus reference files for agent mode, batches, physical devices, the iPhone Duo simulator, recording, settings, sliders and the clipboard. Install it from your AXe binary with `axe init`, or from the AXe plugin marketplace to keep it updated.

## Install from the plugin marketplace

The marketplace keeps the skill updated as releases ship. Keep the CLI on the latest release too, with `brew upgrade axe`.

```shell
claude plugin marketplace add cameroncooke/AXe && claude plugin install axe@axe
```

```shell
codex plugin marketplace add cameroncooke/AXe && codex plugin add axe@axe
```

The marketplace reads the case-sensitive `Skills/CLI` path; clients that require a lowercase `skills/` directory are unsupported.

## Install with `axe init`

`axe init` installs the skill bundled with your AXe binary, so the skill always matches the CLI you have:

```shell
axe init                        # every client it finds
axe init --client claude --force
axe init --client agents
axe init --dest ~/my-skills
axe init --print                # print SKILL.md to stdout
```

| Option | Default | Description |
|--------|---------|-------------|
| `--client auto\|claude\|agents` | `auto` | `auto` installs for every client it finds. |
| `--dest <path>` | | Install into this skills directory instead. |
| `--force` | | Replace an installed skill. |
| `--uninstall` | | Remove the installed skill. |
| `--print` | | Print the bundled `SKILL.md` to stdout. |

| Client | Path |
|--------|------|
| Claude Code | `~/.claude/skills/axe/` |
| Agents (Codex and others) | `~/.agents/skills/axe/` |
| `--dest` | `<dest>/axe/` |

Without a terminal, pass `--client`, `--dest` or `--print`; AXe does not guess.

## Uninstall

```shell
axe init --uninstall --client claude
axe init --uninstall --client agents
```

## What the skill teaches
